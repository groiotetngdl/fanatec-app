## 🕹️ Overview

Fanatec App manages wheelbases, steering wheels, pedals, and handbrakes, providing firmware updates, force feedback tuning, and button mapping for all devices.

Whether you're a newcomer or a veteran, Fanatec App provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
